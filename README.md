# Network Traffic Analysis — Investigating Suspicious Network Activity

**Status:** In Progress  
**Project Type:** Hands-on Cybersecurity Investigation  
**Environment:** Ubuntu Linux  
**Tools:** Wireshark, TShark, Git, VS Code

## Overview

This project focuses on analyzing network traffic captures (PCAP files) to identify potentially suspicious activity, investigate communication patterns, and document technical findings.

## Objectives

- Analyze network traffic and common protocols.
- Understand DNS, TCP, and HTTP communications.
- Identify potentially anomalous network behavior.
- Use Wireshark and TShark for traffic analysis.
- Correlate evidence and document investigation findings.
- Produce a structured technical report.

## Project Structure

- `captures/` — Network traffic capture files.
- `docs/` — Project documentation and technical report.
- `evidence/` — Analysis evidence and investigation findings.
- `screenshots/` — Visual evidence from the investigation.

## Methodology

The investigation will follow a structured process:

1. Environment preparation.
2. Network traffic fundamentals.
3. Suspicious activity investigation.
4. Findings analysis and technical reporting.
5. Portfolio documentation and validation.

## Scope

This is an educational cybersecurity project using controlled and suitable network traffic captures.

No unauthorized network activity is performed.
